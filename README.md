# SpeakReady

SpeakReady הוא פרויקט הגמר שלי בהנדסת תוכנה. מטרת המערכת היא לעזור לתלמידים להתכונן לבגרות בעל פה באנגלית באמצעות מסלול למידה, תרגול שאלות ודיבור באנגלית.

בהמשך הפרויקט מתוכננת גם אפשרות לקבל משוב על תשובות מוקלטות ולעבוד עם מורה.

## מה קיים בפרויקט?

הפרויקט בנוי מארבע שכבות:

| שכבה | תפקיד |
|---|---|
| Model | מחלקות הנתונים של המערכת |
| DAL | עבודה מול בסיס הנתונים MySQL |
| API | קבלת בקשות, ניהול משתמשים והחזרת נתונים |
| View | ממשק המשתמש באמצעות Blazor |

בסיס הנתונים נקרא `SpeakReadyDB` והוא כולל שבע טבלאות לניהול משתמשים, שיעורים, תרגילים, קבוצות למידה, משימות וניסיונות תרגול.

## טכנולוגיות

C#, .NET 10, ASP.NET Core Web API, Blazor, MySQL, HTML, CSS ו-Bootstrap.

## הרצת הפרויקט

יש לפתוח את `SpeakReady.sln` ב-Visual Studio עם .NET 10 ולוודא ששרת MySQL פועל.

בפרויקט API יש להגדיר באמצעות User Secrets את `ConnectionStrings:DefaultConnection` עם פרטי החיבור ל-MySQL, ואת `Seed:DemoPassword` עבור משתמשי ההדגמה.

לאחר מכן יש להפעיל את הפרויקטים API ו-View יחד.

בהרצה הראשונה, ה-API יוצר את בסיס הנתונים ואת הטבלאות אם הם עדיין לא קיימים.

כתובות הפיתוח:

- View: `http://localhost:5012`
- API: `http://localhost:5214`

אפשר לבדוק את פעולות המשתמשים באמצעות הקובץ `API/API.http`.

## מצב הפיתוח הנוכחי

הפרויקט נמצא בשלב 4.

בוצעו הקמת ארבע השכבות, הגדרת בסיס הנתונים, בניית API לניהול משתמשים ועיצוב דף הבית, דף ההתחברות ודף ההרשמה.

בשלב הנוכחי מסכי ההתחברות וההרשמה הם עיצוב בלבד. החיבור שלהם ל-API ומערכת תרגול הדיבור יפותחו בהמשך.

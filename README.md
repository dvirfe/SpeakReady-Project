# SpeakReady

SpeakReady הוא פרויקט הגמר שלי בהנדסת תוכנה.
מטרת המערכת היא לעזור לתלמידים להתכונן לבגרות בעל פה באנגלית.

בהמשך יתווספו מסלול למידה, תרגול דיבור, משוב על תשובות מוקלטות ואפשרות לליווי מורה.

## מבנה הפרויקט

הפרויקט בנוי מארבע שכבות:

- Model: מחלקות הנתונים של המערכת.
- DAL: עבודה מול בסיס הנתונים MySQL.
- API: קבלת בקשות מהאתר והפעלת פעולות על הנתונים.
- View: ממשק המשתמש באמצעות Blazor.

## טכנולוגיות

C#, .NET 10, ASP.NET Core Web API, Blazor, MySQL, HTML, CSS ו-Bootstrap.

## שלבי הפיתוח שבוצעו

### שלבים 1–4: הקמת הפרויקט

- יצירת ארבע השכבות וחיבור ביניהן.
- הקמת בסיס הנתונים SpeakReadyDB והטבלאות.
- בניית פעולות API לניהול משתמשים.
- יצירת קובץ API.http לבדיקת הפעולות.
- עיצוב דף הבית, דף ההרשמה ודף הכניסה.

### שלב 5: הרשמה

- חיבור טופס ההרשמה ל-API ולבסיס הנתונים.
- בדיקת שדות חובה, כתובת אימייל והתאמה בין הסיסמאות.
- בדיקה ששם המשתמש והאימייל אינם רשומים כבר.
- שמירת משתמש חדש והצגת הודעת הצלחה.
- מעבר לדף הכניסה לאחר ההרשמה.

### שלב 6: התחברות ושמירת מצב משתמש

- כניסה באמצעות שם משתמש או אימייל וסיסמה.
- בדיקת פרטי הכניסה ושהחשבון פעיל.
- שמירת פרטי המשתמש המחובר באמצעות UserSession במהלך הגלישה.
- הצגת שם המשתמש בתפריט ואפשרות להתנתק.

### שלב 7: גיבוב סיסמאות

- שימוש ב-BCrypt לגיבוב סיסמאות לפני שמירתן.
- אימות הסיסמה בזמן ההתחברות מול הגיבוב השמור.
- גיבוב הסיסמה גם בעת עדכון סיסמה ויצירת משתמשי הדגמה.

### שלב 8: רמות הרשאה

- שלושה תפקידים: תלמיד, מורה ומנהל.
- דף ראשי נפרד לכל תפקיד.
- מעבר לדף המתאים לאחר התחברות.
- הצגת קישור בתפריט בהתאם לתפקיד.
- העברת אורחים שמנסים לפתוח דף מוגן לדף הכניסה.
- העברת משתמשים בתפקיד לא מתאים לדף "אין הרשאה".

ההגנה בשלב זה היא בתצוגה בלבד ואינה הגנה מלאה על ה-API.
הדפים של התפקידים כוללים כרגע כותרת בלבד. העיצוב שלהם יבוצע בשלב 9.

## הרצת הפרויקט

1. פותחים את SpeakReady.sln ב-Visual Studio עם .NET 10.
2. מוודאים ששרת MySQL פועל.
3. בפרויקט API פותחים Manage User Secrets ומגדירים:
   - ConnectionStrings:DefaultConnection עם פרטי החיבור ל-MySQL.
   - Seed:DemoPassword עם סיסמה למשתמשי ההדגמה.
4. מפעילים את API ואת View יחד.

ה-API יוצר את בסיס הנתונים ואת הטבלאות אם הם אינם קיימים.
משתמשי ההדגמה נוצרים כאשר טבלת המשתמשים ריקה ומוגדרת סיסמת הדגמה.

כתובות הפיתוח:

- אתר: http://localhost:5012
- API: http://localhost:5214

אפשר לבדוק את פעולות המשתמשים באמצעות API/API.http.

## המשך הפיתוח

עיצוב הדפים הפנימיים והוספת יכולות הלמידה, תרגול הדיבור והמשוב.
